# EComm-App

Spring Boot microservices for an e-commerce application. Start with the [Identity Service](services/identity-service/README.md).

The service implements registration, login, RSA-signed access tokens, rotating hashed refresh tokens, logout, account management, role-based authorization, Swagger, Flyway, MySQL and Docker support.

See the [architecture and execution-order walkthrough](services/identity-service/docs/ARCHITECTURE.md) for the package structure, database evolution, security flow and downstream integration.
